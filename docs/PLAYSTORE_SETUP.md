## Permission Declarations

### Camera

```text
Muv'it uses the camera so users can record Muv'z, create profile media and start live streams. Camera access is used only when the user chooses to record, upload or go live.
```

### Microphone

```text
Muv'it uses the microphone so users can record audio with Muv'z and broadcast audio during live streams. Microphone access is used only when the user records or starts a live feature.
```

### Location

```text
Muv'it uses location to help users discover nearby Muva'z, suggested creators and local dance content, including nearby discovery within a chosen distance such as 20 km. Location access is optional and can be disabled in device settings.
```

### Notifications

```text
Muv'it uses notifications to alert users about likes, comments, replies, follows, mentions, messages, battle updates, live streams, upload processing, earnings and important Muv'it announcements. Users can manage notification categories inside Muv'it and through device settings.
```

### Photos and Videos

```text
Muv'it uses photos and videos access so users can select videos, thumbnails, profile pictures and other media from their device for Muv'z, profiles and creator features.
```

## Data Safety Notes

Data collected:

- Email address and account identifiers
- Username, display name, profile picture and profile details
- Uploaded videos, thumbnails, captions, hashtags and comments
- Likes, follows, messages, battle activity, live activity and notification preferences
- Device identifiers used for push notifications
- Approximate or precise location when enabled by the user
- App diagnostics, crash logs and performance information
- Payment, gifts, coins, monetization and payout-related data where features are available

Data sharing:

```text
Muv'it does not sell personal information. Data may be shared with service providers needed to operate the app, including hosting, database, storage, authentication, push notifications, live streaming, analytics, moderation and payment services.
```

Security:

```text
Muv'it uses secure transmission, protected backend services and access controls to help protect user data.
```

Account deletion:

```text
Users can request account deletion through the app's account/settings options or by contacting support@muvit.app.
```
